# REST API для ФСТР (Федеральная служба по техническому регулированию и метрологии)

## Описание
API для добавления, просмотра и редактирования данных о перевалах.

## Методы
- `POST /submitData` — добавление нового перевала.
- `GET /submitData/{id}` — получение информации о перевале по ID.
- `PATCH /submitData/{id}` — редактирование перевала (если статус new).
- `GET /submitData/?user__email={email}` — получение списка перевалов пользователя.

## Документация
После запуска сервера документация доступна по адресу `/docs` (Swagger).
